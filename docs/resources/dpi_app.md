# Dpi App (Resource)

Manages a DPI application rule: a set of deep-packet-inspection applications or categories the controller blocks or logs, with optional QoS rate caps.

## Example Usage

```terraform
# unifi_dpi_app manages a DPI application rule: a set of deep-packet-inspection
# applications or categories the controller blocks or logs, with optional QoS
# rate caps.
resource "unifi_dpi_app" "block_streaming" {
  name    = "block-streaming"
  enabled = true
  blocked = true
  log     = true
  cats    = [4]
}
```

## Schema

### Required

- `name` (String) The name of the DPI application rule.

### Optional

- `apps` (List of Number) The DPI application identifiers the rule matches.
- `blocked` (Boolean) Whether traffic the rule matches is blocked.
- `cats` (List of Number) The DPI category identifiers the rule matches.
- `enabled` (Boolean) Whether the rule is enabled.
- `log` (Boolean) Whether traffic the rule matches is logged.
- `qos_rate_max_down` (Number) The download rate cap in Kbps applied to matched traffic, or `-1` for no cap.
- `qos_rate_max_up` (Number) The upload rate cap in Kbps applied to matched traffic, or `-1` for no cap.
- `site` (String) The name of the site the DPI application rule belongs to.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))

### Read-Only

- `id` (String) The ID of the DPI application rule.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# DPI application rules can be imported using the rule ID.

terraform import unifi_dpi_app.block_streaming default:5f3e9b2c4ee8cb0f1f4a1234
```
