# Nat (Resource)

Manages a source NAT rule: the controller rewrites the address of traffic leaving a WAN interface, most commonly masquerading a network behind the WAN's own address.

## Example Usage

```terraform
# unifi_nat manages a source NAT rule. out_interface is the _id of a WAN
# network, not the literal "wan" -- the controller rejects anything that is
# not a WAN networkconf. The sim and a fresh site ship no WAN, so create one
# with unifi_wan and reference its id.
resource "unifi_wan" "primary" {
  name    = "WAN"
  type    = "dhcp"
  enabled = true
}

# Masquerade a LAN behind the WAN interface's own address.
resource "unifi_nat" "masquerade" {
  description   = "masquerade lan"
  type          = "MASQUERADE"
  out_interface = unifi_wan.primary.id

  source_filter = {
    filter_type = "NONE"
  }

  destination_filter = {
    filter_type = "NONE"
  }
}
```

## Schema

### Required

- `destination_filter` (Attributes) Which traffic the rule matches on its destination address and port. Leave `filter_type` at `NONE` to match any destination. (see [below for nested schema](#nestedatt--destination_filter))
- `out_interface` (String) The outbound interface the rule masquerades on: the `_id` of a WAN `unifi_network`, not the literal `wan`.
- `source_filter` (Attributes) Which traffic the rule matches on its source address and port. Leave `filter_type` at `NONE` to match any source. (see [below for nested schema](#nestedatt--source_filter))
- `type` (String) The kind of NAT the rule performs: `DNAT`, `SNAT` or `MASQUERADE`.

### Optional

- `description` (String) A human-readable description of the NAT rule.
- `enabled` (Boolean) Whether the rule is enabled.
- `in_interface` (String) The inbound interface the rule matches on. Usually left unset for a source NAT rule.
- `ip_address` (String) The address traffic is translated to. Empty for `MASQUERADE`, which uses the outbound interface's own address.
- `ip_version` (String) The IP version the rule applies to: `IPV4` or `IPV6`.
- `logging` (Boolean) Whether traffic the rule matches is logged.
- `port` (Number) The translated port, for a `DNAT` rule that also rewrites the port.
- `protocol` (String) The protocol the rule matches: `all`, `tcp`, `udp` or `tcp_udp`. The controller requires this on every write.
- `setting_preference` (String) Whether the controller orders the rule automatically (`auto`) or honours `rule_index` (`manual`).
- `site` (String) The name of the site the NAT rule belongs to.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))

### Read-Only

- `exclude` (Boolean) Whether the rule excludes rather than includes the matched traffic. Controller-managed.
- `id` (String) The ID of the NAT rule.
- `is_predefined` (Boolean) Whether the rule is one the controller ships. Controller-managed.
- `pppoe_use_base_interface` (Boolean) Whether a PPPoE outbound interface masquerades on its base interface. Controller-managed.
- `rule_index` (Number) The rule's position in the controller's evaluation order. Controller-assigned.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# NAT rules can be imported using the rule ID.
terraform import unifi_nat.example 5f3e9b2c4ee8cb0f1f4a1234

# For a non-default site, prefix the ID with the site name and a colon.
terraform import unifi_nat.example default:5f3e9b2c4ee8cb0f1f4a1234
```
