# Wlan Group (Resource)

Manages a WLAN group. Every wireless network belongs to a group; the controller ships a built-in `Default` one and `unifi_wlan` assigns new networks to a group automatically.

## Example Usage

```terraform
# unifi_wlan_group manages a WLAN group. Every wireless network belongs to a
# group; the controller ships a built-in "Default" one.
resource "unifi_wlan_group" "example" {
  name = "example"
}
```

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# WLAN groups can be imported using the group ID.
terraform import unifi_wlan_group.example 5f3e9b2c4ee8cb0f1f4a1234

# For a non-default site, prefix the ID with the site name and a colon.
terraform import unifi_wlan_group.example default:5f3e9b2c4ee8cb0f1f4a1234
```
