# Schedule Task (Resource)

Manages a scheduled task in the UniFi controller. A schedule task upgrades the firmware of one or more adopted devices, either once or on a repeating cron schedule.

## Example Usage

```terraform
# A weekly firmware upgrade for two access points, running at 04:00 every
# Sunday.
resource "unifi_schedule_task" "weekly" {
  name              = "weekly-ap-upgrade"
  cron_expr         = "0 4 * * 0"
  execute_only_once = false

  upgrade_targets = [
    { mac = "00:11:22:33:44:55" },
    { mac = "00:11:22:33:44:66" },
  ]
}

# A one-off upgrade of a single switch at the next matching time.
resource "unifi_schedule_task" "one_off" {
  name              = "switch-upgrade"
  cron_expr         = "30 2 * * *"
  execute_only_once = true

  upgrade_targets = [
    { mac = "00:11:22:33:44:77" },
  ]
}
```

## Schema

### Required

- `cron_expr` (String) The cron expression fixing when the task runs. A once-only task runs at the first matching time and then stops.
- `execute_only_once` (Boolean) Whether the task runs a single time (`true`) or repeats on every match of its cron expression (`false`).
- `name` (String) The name of the scheduled task.
- `upgrade_targets` (Attributes List) The devices the task upgrades, each named by its MAC address. (see [below for nested schema](#nestedatt--upgrade_targets))

### Optional

- `action` (String) The action the task performs. The controller only schedules firmware upgrades, so `upgrade` is the sole value.
- `site` (String) The name of the site the scheduled task belongs to.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))

### Read-Only

- `id` (String) The ID of the scheduled task.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# Scheduled tasks can be imported using the task ID.
terraform import unifi_schedule_task.weekly 5f3e9b2c4ee8cb0f1f4a1234

# For a non-default site, prefix the ID with the site name and a colon.
terraform import unifi_schedule_task.weekly default:5f3e9b2c4ee8cb0f1f4a1234
```
