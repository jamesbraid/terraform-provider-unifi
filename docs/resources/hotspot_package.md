# Hotspot Package (Resource)

Manages a hotspot package: a guest-portal access plan, either a timed free trial or an hourly paid plan. The controller's sanitizer requires exactly one of `trial_duration_minutes` (free trial, `amount` zero) or `hours` (paid, `amount` non-zero) on every write, including a masked update that only touches an unrelated attribute -- so `trial_duration_minutes` is forced Required here and always joins the write mask. Only the free-trial branch is exercised by this resource today; the paid branch needs `trial_duration_minutes` absent, which a Required attribute cannot express.

## Schema

### Required

- `name` (String) The name of the hotspot package.
- `trial_duration_minutes` (Number) The length of the free trial in minutes. The controller requires this on every create and refuses a masked update that names any field without also naming this one, so it is always part of the write.

### Optional

- `amount` (Number) The price of the package. Zero (the default when unset) makes the package a free trial, priced by `trial_duration_minutes`; a non-zero amount prices it by the hour instead, through `hours`.
- `charged_as` (String) How a paid package is charged, e.g. `hour`. Only meaningful when `amount` is non-zero.
- `currency` (String) The three-letter ISO 4217 currency code `amount` is priced in, e.g. `USD`. Only meaningful when `amount` is non-zero.
- `custom_payment_fields_enabled` (Boolean) Whether the guest-portal payment form collects the fields below rather than the controller's own default set.
- `hours` (Number) The number of hours a paid package grants access for. Set only when `amount` is non-zero; the controller's sanitizer refuses a package carrying both this and `trial_duration_minutes`.
- `index` (Number) The package's position in the site's hotspot package list.
- `limit_down` (Number) The download rate limit applied to a client on this package, gated by `limit_overwrite`.
- `limit_overwrite` (Boolean) Whether this package overrides the site's default rate and quota limits with `limit_down`, `limit_up` and `limit_quota`.
- `limit_quota` (Number) The data quota applied to a client on this package, gated by `limit_overwrite`.
- `limit_up` (Number) The upload rate limit applied to a client on this package, gated by `limit_overwrite`.
- `payment_fields_address_enabled` (Boolean) Whether the guest-portal payment form collects an address.
- `payment_fields_address_required` (Boolean) Whether the address the payment form collects is required rather than optional.
- `payment_fields_city_enabled` (Boolean) Whether the guest-portal payment form collects a city.
- `payment_fields_city_required` (Boolean) Whether the city the payment form collects is required rather than optional.
- `payment_fields_country_enabled` (Boolean) Whether the guest-portal payment form collects a country.

- `payment_fields_email_enabled` (Boolean) Whether the guest-portal payment form collects an email address.
- `payment_fields_email_required` (Boolean) Whether the email address the payment form collects is required rather than optional.
- `payment_fields_first_name_enabled` (Boolean) Whether the guest-portal payment form collects a first name.
- `payment_fields_first_name_required` (Boolean) Whether the first name the payment form collects is required rather than optional.
- `payment_fields_last_name_enabled` (Boolean) Whether the guest-portal payment form collects a last name.
- `payment_fields_last_name_required` (Boolean) Whether the last name the payment form collects is required rather than optional.
