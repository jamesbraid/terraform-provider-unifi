# Ospf Router (Resource)

Manages an OSPF router in the UniFi controller. An OSPF router announces the networks assigned to its areas to neighbouring routers and can redistribute BGP, connected and static routes.

## Example Usage

```terraform
# An OSPF router announcing two networks into the backbone area
resource "unifi_ospf_router" "backbone" {
  router_id = "10.255.0.1"

  areas = [{
    area_id = "0.0.0.0"
    name    = "backbone"
    network_ids = [
      unifi_network.lan.id,
      unifi_network.iot.id,
    ]
  }]
}

# Redistribute static and connected routes, with per-interface settings
resource "unifi_ospf_router" "full" {
  router_id              = "10.255.0.2"
  announce_default_route = true

  redistribute_static_routes    = true
  redistribute_connected_routes = true

  areas = [{
    area_id     = "0.0.0.1"
    name        = "branch"
    network_ids = [unifi_network.branch.id]
  }]

  interfaces = [{
    network_id     = unifi_network.branch.id
    cost           = "10"
    hello_interval = "10"
    dead_interval  = "40"
  }]
}
```

## Schema

### Required

- `areas` (Attributes List) OSPF areas this router participates in. The controller refuses a router with no areas. (see [below for nested schema](#nestedatt--areas))
- `router_id` (String) The router's OSPF identifier, in dotted-quad form. The controller refuses an empty one.

### Optional

- `announce_default_route` (Boolean) Whether the router announces a default route to its neighbours.
- `enabled` (Boolean) Whether the OSPF router is enabled.
- `interfaces` (Attributes List) Per-interface OSPF settings, keyed by the network the interface serves. (see [below for nested schema](#nestedatt--interfaces))
- `redistribute_bgp_routes` (Boolean) Whether routes learned over BGP are redistributed into OSPF.
- `redistribute_connected_routes` (Boolean) Whether directly connected routes are redistributed into OSPF.
- `redistribute_connected_routes_metric_type` (String) The OSPF metric type used when redistributing connected routes.
- `redistribute_static_routes` (Boolean) Whether static routes are redistributed into OSPF.
- `redistribute_static_routes_metric_type` (String) The OSPF metric type used when redistributing static routes.
- `site` (String) The name of the site to associate the OSPF router with.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))

### Read-Only

- `id` (String) The ID of the OSPF router.
